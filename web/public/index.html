TerminIAtor

Cree une session IA temporaire d'equipe dans l'AWS de ton entreprise.

Session d'equipe

Donne un nom a la session, choisis sa duree, puis prepare l'acces pour tes utilisateurs.

Mode d'acces

Le mode standard connecte les utilisateurs sans mot de passe local. L'adresse reseau est detectee automatiquement.

Parametres avances

Le CIDR est rempli automatiquement avec ton IP publique. Tu peux le modifier si ton reseau change.
