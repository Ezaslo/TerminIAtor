Administration Privalyse

Gérez les utilisateurs, les groupes et les paramètres de sécurité de votre environnement.

Changer mon mot de passe

Modifiez le mot de passe de votre propre compte Privalyse. Les autres connexions ouvertes seront déconnectées.

Entre 12 et 200 caractères.

Authentification à deux facteurs

Protégez votre compte avec une application TOTP.

1. Scannez le QR code avec votre application.
2. Saisissez le code à 6 chiffres.
3. Conservez ensuite les codes de récupération.

Clé manuelle

Ces codes ne seront affichés qu’une seule fois.


      
Désactiver la MFA
La désactivation déconnectera vos sessions actives.
